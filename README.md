

**Zomra** (زمرة) هي منصة اجتماعية مخصصة للطلاب، بتجمع بين الفيد الاجتماعي وأدوات المذاكرة والتعاون الدراسي في مكان واحد.

🔗 **الموقع المباشر:** [zomra.codematrix1.workers.dev](https://zomra.codematrix1.workers.dev/)

## نبذة عن المشروع

Zomra مش مجرد سوشيال ميديا عادي - هي مساحة مصممة خصيصًا للطلاب عشان يتواصلوا، يتشاركوا الملخصات، يذاكروا مع بعض، ويحافظوا على حماسهم الدراسي من خلال نظام نقاط وشارات وستريك يومي.

## المميزات الرئيسية

### 📱 الفيد الاجتماعي
- منشورات بنص وصور
- ستوريز تختفي بعد 24 ساعة
- لايكات، تعليقات، وحفظ المنشورات (Bookmarks)
- فلترة الفيد (الكل / اللي بتتابعهم)

### 📚 مكتبة الملخصات والريلز
- رفع ومشاركة ملخصات دراسية (PDF أو صور) مصنفة حسب المادة والمرحلة الدراسية
- ريلز تعليمية بأسلوب تيك توك مع تشغيل تلقائي

### 👥 مجموعات ومشاريع دراسية
- إنشاء مجموعات دراسية بشات جماعي لحظي
- مشاريع دراسية مشتركة مع تتبع المهام ونسبة الإنجاز

### ❓ أسئلة وأجوبة
- قسم مخصص لطرح الأسئلة الدراسية
- تحديد "الحل المعتمد" من صاحب السؤال
- نقاط مكافأة لأصحاب أفضل الإجابات

### 🏆 التحفيز والإنجاز
- نظام نقاط يتجمع من النشاط (نشر، رفع ملخصات، إجابة أسئلة)
- ستريك يومي (Study Streak) لتشجيع الاستمرارية
- شارات إنجاز (Badges) عند الوصول لمعالم معينة
- لوحة متصدرين (Leaderboard)
- تحدي أسبوعي (Weekly Challenge)

### 💬 التواصل
- شات مباشر بين الطلاب
- إشعارات فورية (لايكات، تعليقات، متابعات، رسائل)

### ⚙ إعدادات وتخصيص
- نظام ألوان كامل قابل للتخصيص
- دعم كامل للغتين العربية والإنجليزية
- خصوصية البروفايل وحظر المستخدمين
- **وضع تجميد الامتحانات (Exam Freeze Mode):** تجميد الإشعارات والرسائل الواردة تلقائيًا خلال فترة الامتحانات
- تصدير البيانات الشخصية
- تعطيل أو حذف الحساب

### 📲 تطبيق ويب تقدمي (PWA)
Zomra قابل للتثبيت على الشاشة الرئيسية في الآيفون والأندرويد والكمبيوتر، ويشتغل زي تطبيق حقيقي.

## التقنيات المستخدمة

- **الواجهة الأمامية:** HTML, CSS, JavaScript (Vanilla, بدون فريمورك)
- **قاعدة البيانات والمصادقة:** [Supabase](https://supabase.com/) (PostgreSQL + Realtime + Storage + Auth)
- **الاستضافة:** [Cloudflare Workers](https://workers.cloudflare.com/)
