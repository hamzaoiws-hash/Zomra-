# 🎓 Zomra (زُمرة)

**Zomra** هي منصة اجتماعية تعليمية مخصصة للطلاب، تهدف إلى تسهيل التواصل، مشاركة الملخصات والمصادر الدراسية، متابعة التقدم، والتعاون في مجموعات دراسية ومشاريع مشتركة.

---

## ✨ المميزات الرئيسية (Key Features)

* **شريط المنشورات (Feed):** مشاركة التحديثات، الأسئلة، والأفكار مع تدعم التصفح المترابط والتفاعل.
* **المكتبة والملخصات (Library):** رفع ومشاركة الملخصات والمواد الدراسية حسب المادة.
* **الريلز التعليمية (Reels):** فيديوهات قصيرة مع تشغيل تلقائي لعرض المحتوى التعليمي السريع.
* **المجموعات والمشاريع (Groups & Projects):** إنشاء مجموعات دراسية وإدارة المشاريع الجماعية.
* **نظام النقاط والاستمرارية (Points & Streaks):** تحفيز الطلاب على الاستمرار في التعلم اليومي.
* **لوحة تحكم المشرفين (Admin Dashboard):** إدارة كاملة للمستخدمين، المنشورات، الملخصات، والمحتوى المرفوع.
* **دعم متعدد اللغات (i18n):** دعم كامل للغتين العربية والإنجليزي مع ضبط الاتجاه تلقائيًا (RTL / LTR).
* **تصميم متجاوب (Responsive Design):** وضع داكن وفاتح مع واجهة سلسة مخصصة للموبايل والحاسوب.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Front-end:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Back-end & Database:** [Supabase](https://supabase.com/) (Database, Auth, Realtime)
* **Libraries:** `@supabase/supabase-js`
